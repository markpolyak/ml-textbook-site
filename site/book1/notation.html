Основные обозначения

Латинские буквы набраны курсивом, векторы и матрицы — прямым полужирным шрифтом. Обозначения, которые нужны только в одной главе, вводятся там же.

X, Y — множество объектов и множество ответов;

\varphi \colon X \to Y — неизвестная зависимость, которую восстанавливает модель;

x, x_i — объект; i-й объект выборки;

f_j(x) — j-й признак объекта, j = 1, \ldots, n; f_0(x) = 1 — фиктивный признак;

x_{ij} = f_j(x_i) — значение j-го признака на i-м объекте;

\mathbf{x}_i — признаковое описание объекта x_i (вектор значений его признаков);

n, \ell — число признаков и число объектов обучающей выборки;

X^\ell = (x_i, y_i)_{i=1}^{\ell} — обучающая выборка; X^k — тестовая выборка из k объектов;

\mathbf{F} — матрица объекты–признаки: \ell строк (объекты), столбцы — признаки;

\mathbf{y} — вектор ответов (y_1, \ldots, y_\ell)^{\mathrm{T}};

\tilde y \in \{0, 1\} — метка класса в записи 0/1, \tilde y = (y + 1)/2 для y \in \{-1, +1\};

K — число классов;

\boldsymbol{\theta} = (\theta_0, \ldots, \theta_n) — вектор параметров модели;

g(x, \boldsymbol{\theta}) — модель: прогноз ответа на объекте x;

\hat y = g(x, \boldsymbol{\theta}) — прогноз модели;

\boldsymbol{\theta}^* — оптимальные параметры: решение задачи обучения;

h(x, \boldsymbol{\theta}) — разделяющая функция классификатора: g = \operatorname{sign} h;

\mathcal{M} — метод обучения: по выборке находит параметры, \mathcal{M}(X^\ell) = \boldsymbol{\theta};

\mathcal{L} — функция потерь (ошибка модели на одном объекте);

Q(\boldsymbol{\theta}, X^\ell) — функционал качества; чаще всего — эмпирический риск (средняя потеря на выборке);

\nabla Q — градиент функции Q по параметрам;

\eta — скорость обучения в градиентном спуске;

\lambda — коэффициент регуляризации;

M_i — отступ объекта x_i;

\sigma(z) — сигмоида (с аргументом); \sigma, \sigma_j без аргумента — стандартное (среднеквадратическое) отклонение;

P(\cdot), p(\cdot) — вероятность и плотность распределения;

\hat p = P(\tilde y = 1 \mid x) — вероятность класса 1, предсказанная моделью для объекта x; \hat p_i — для объекта x_i;

\mathbb{E}(\cdot), \mathrm{D}(\cdot) — математическое ожидание и дисперсия;

[A] — индикатор: 1, если утверждение A истинно, иначе 0;

\langle \mathbf{a}, \mathbf{b} \rangle — скалярное произведение векторов;

\|\boldsymbol{\theta}\|_2, \|\boldsymbol{\theta}\|_1 — нормы вектора: евклидова и сумма модулей;

\mathbf{A}^{\mathrm{T}} — транспонированная матрица;

s_j — сингулярные числа матрицы \mathbf{F};

\kappa — число обусловленности матрицы;

\mathbf{I} — единичная матрица.
