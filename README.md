# Учебные пособия по машинному обучению

Веб-версия серии учебных пособий М. Д. Поляка: https://markpolyak.github.io/ml-textbook-site/

Здесь лежит только собранный сайт (каталог `site/`: HTML-страницы глав и PDF для скачивания) и
настройка его публикации на GitHub Pages. Исходные тексты книг в этом репозитории не хранятся.

## Сообщить об ошибке

Если вы нашли опечатку или ошибку в тексте, формуле или примере, откройте задачу (issue) в этом
репозитории: укажите книгу, главу и цитату. Ссылка «Сообщить об ошибке» есть внизу каждой главы.
